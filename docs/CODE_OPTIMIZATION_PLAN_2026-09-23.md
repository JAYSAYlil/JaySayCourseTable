# v3.4.33 代码等价优化计划与本地交付记录

目标：在不增减功能、不改变布局、文案、颜色、动画、交互与数据格式的前提下，减少课表绘制和月视图统计中的重复计算。本轮先完成以下可验证的三项，不做全应用重构。

| 优先级 | 位置 | 现状 | 建议 | 等价性边界 |
| --- | --- | --- | --- | --- |
| 1 | `CourseTableScreen.kt` 月课程总数 | 每月约 28–31 天逐日调用解析器，每次传入整张课程表与全部日期例外 | 一次建立 `ScheduleDateResolver.Prepared`，逐日查询其 `coursesOn` | 计数与顺序、停课/取消/补课、学期外日期和搜索过滤均不变；不要跨输入变化缓存 |
| 2 | `MonthGrid.kt` 日期格 | 已按星期分组课程，但每天仍传入完整例外列表进行筛选 | 本次月格计算中建立 `Prepared` 并复用 | 日期高亮、农历、节日、周标签、课程名与节数保持完全相同 |
| 3 | `ScheduleGrid.kt` 周/日网格 | 每列、每条网格线及时间线重复遍历节次分组求垂直偏移；当天课程还按已分组的星期重复过滤 | 随 `periodTimes` 与 `cellHeight` 变化预计算偏移；当天直接使用已分组课程 | 所有节次位置逐像素等价；保留空节次、零节次、单日/五日/七日与时间栏显示/隐藏的行为 |

执行顺序：先做月视图两项，再做网格偏移；每项只改计算路径，保持现有 Compose 结构和控件参数。若等价性无法明确证明，放弃该项并记录原因。禁止改课程编辑三档范围、导入解析、持久化、提醒调度、Hero 转场、布局数值、主题色以及用户可见文案。交付安装包时只推进版本元数据；不发布到 GitHub。

验收：审查差异确认只有等价计算和必要测试；运行 JVM 单元测试、API 34 界面回归、Release Lint/构建与仓库发布前审计。补充仅针对真实风险的等价测试；测试完成前不宣称性能提升比例。

审查过但本轮不改的路径：自定义背景解码已由 `produceState` 按版本异步加载；仓库读写已在 IO 调度器且写入由 ViewModel 串行保护；每周提醒计算已经使用 `Prepared`。这些地方没有发现足以支持安全改动的重复热路径。Excel 导入与备份属于低频高风险流程，在没有复现的性能问题和对应基准前不改写。

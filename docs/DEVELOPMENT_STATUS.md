- 课程详情页返回课表或日程列表时，取消大幅横向滑动，改为 150 ms 淡入与 90 ms 淡出的短过渡；系统“减少动态效果”开启时继续禁用动画。
- 自定义背景启用时，课表根背景改为绘制到系统栏区域，图片和遮罩可以完整覆盖手机状态栏及导航栏背后区域。
- 课表标题、周切换、课程网格等实际内容继续使用状态栏和导航栏安全间距，不会被打孔、刘海、状态栏或底部手势区遮挡。
- 未启用自定义背景以及设置、详情等其他页面继续使用原有系统栏布局，避免无关界面发生位置变化。

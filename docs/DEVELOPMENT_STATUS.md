# v2.18.1 开发交接状态

更新时间：2026-08-26

## 本轮（v2.18.1）：学期安排交互补全与背景遮罩控制

- 课表校历提示条可直接进入学期安排，并按进入来源正确返回。
- 具体日期安排支持原位编辑，添加按钮与周标签统一；保存保留原记录 ID，不产生重复。
- 自定义背景可读遮罩可由用户开关，旧设置与旧备份默认开启，保持升级后的原显示效果。
- 320×640 模拟器人工复核添加入口、编辑弹窗、课表直达提示条和遮罩设置布局。

## v2.18.0 基线：学期安排、可见状态、防回归与结构优化

- “学期安排”统一管理停课周、周标签与具体日期安排；设置即时保存，整个学期均可滚动选择。
- 停课周与搜索空结果仍保留课表横向切周手势；课表和小组件都会解释周标签、停课与日期调整状态。
- 新增 `AcademicCalendarStatusResolver`，由课表和小组件共用校历展示语义，避免不同入口各自计算后产生偏差。
- 新增三种视图、深浅色、自定义背景和紧凑屏视觉契约，并修复单日课程名末端亚像素裁切。
- Android 12+ 小组件改用 `RemoteCollectionItems`，Android 8–11 保留旧服务；条目布局与稳定 ID 共用。
- 提醒恢复广播增加事件白名单，移除厂商检测私有 API 反射；动态快捷方式增加匿名使用上报。
- `CourseTableScreen.kt` 从 1093 行降至约 667 行，网格/卡片拆到 `ScheduleGrid.kt`；小组件解析与页面返回规则也分别拆分。
- 新增 JDK 17 构建预检，发布审计会校验版本、SDK、Gradle 与文档同步。

- **Hero 详情转场中断续接**：飞行进度实时登记，返回/重入/旋转从当前在途进度续接，不再先跳端点再起飞；种子逻辑有 JVM 测试。

- **顶栏**：紧凑宽度导入收进更多菜单（空课表仍保留明显导入按钮）；浏览非今日日期时“回到今天”直达；搜索框展开即持焦。

- **性能**：课程配色映射一次性构建（O(n²)→O(n)）；视图模式切换即时更新 UI、写入移入后台且不再产生无意义课程历史快照（失败时回滚展示状态）；Macrobenchmark 脚手架与 benchmark 变体就绪（无网络/真机，未取得数值）。
- **拆分**：主屏静态区块（星期条/日期表头/进度标尺/校历提示条/空课表）提取为 `ui/screen/CourseTableSections.kt`，行为不变。

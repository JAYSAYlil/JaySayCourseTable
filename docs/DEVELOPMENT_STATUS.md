## v2.11.0 改动

- 删除“课程信息密度”：该选项原先只改变课程行高，没有增加、减少或重排信息，现统一回到各视图经过验证的固定行高。
- 删除“小组件隐私模式”：它与本版明确要求课程名、教室、教师完整显示冲突；旧 JSON 中相关字段会被解析器安全忽略，不影响升级。
- 小组件默认由启动器识别为 3 列×2 行，仅允许横向调整为 4 列或 5 列。
- 3×2 仅展示今日课程；4×2 和 5×2 使用今日/明日左右双栏，每栏可独立滚动。
- 顶部固定显示自然日期与星期；每条课程保留时间、课程名、教室和教师，不使用省略号或最大行数，空字段显示明确占位文案。
- 小组件继续使用 `ScheduleDateResolver`，因此停课周、整日停课、单课取消、补课和学期范围与主课表保持一致。
- 新增课程条目点击直达、无障碍完整朗读、浅色/深色资源和低测量开销的 RemoteViews 布局。

## 数据与兼容性

- `tables.json` 仍为 schemaVersion 4，本轮没有新增持久化字段。
- `preferences.json` 仍为 schemaVersion 3；保存时不再写入废弃的密度和小组件隐私字段，读取旧版多余字段时保持向后兼容。
- 课程、偏好、历史快照、提醒和导入草稿仍全部保存在应用私有目录。
- 应用仍不声明 `INTERNET` 权限，系统云备份与设备迁移数据提取继续关闭。

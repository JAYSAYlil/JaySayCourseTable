# v2.15.0 开发交接状态

更新时间：2026-08-21

## 本轮改动（v2.15.0）：重做提醒后台保活机制

- 新增 ReminderKeepAliveService 轻量前台保活服务：同进程、无 WakeLock、无联网、60 秒内存级心跳；前台通知静默渠道；仅在“提醒开启或桌面有小组件”时运行，条件消失自动退出，被杀自动重启。
- 调度链路：setAlarmClock（用户可见闹钟）→ 精确闹钟 → 近似闹钟降级链；每次重排写入诊断记录（N 条/无未来提醒）。
- 小组件接入保活：心跳按课程状态指纹变化才刷新；小组件添加时启动服务（onEnabled）。
- 暂停恢复闭环：暂停即推送“已暂停，点此恢复”通知（含恢复按钮）；心跳自动清理过期暂停。
- 设置页新增厂商自启动提示与跳转应用系统设置入口。
- 测试：JVM 114 项；API 34 UI 测试 24 项（提醒 E2E 5 项、设置页提醒区 3 项）；模拟器实测杀进程后服务自愈、14:25 闹钟准点触发通知、诊断完整记录。

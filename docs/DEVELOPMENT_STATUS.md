## 本轮改动（v2.16.0）：移除保活机制，改为系统白名单方案

- 删除前台保活服务 ReminderKeepAliveService、诊断 ReminderDiagnostics 及全部接线、ForegroundService 权限与服务声明。
- 上课提醒默认关闭（reminderEnabled 默认 false）；开启时弹确认框说明后台运行/续航影响，确认后引导跳转系统自启动设置。
- 新增 AutostartHelper：按厂商尝试跳转自启动管理页，失败回退应用详情页。
- 删除测试通知按钮、触发诊断记录等测试功能；过期暂停清理保留（应用打开重排时执行）。
- 保留 setAlarmClock 调度、通知权限/精确闹钟/通知渠道/电池优化引导、暂停恢复入口（设置页）。

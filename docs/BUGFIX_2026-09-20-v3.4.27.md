# BUGFIX 2026-09-20 v3.4.27：删除没有跟随“应用到本周及以后周次”

## 现象

课程编辑弹窗里打开“应用到本周及以后周次”后：

- 点“保存” → 第 N 周及其之后的周次按新内容生效（正确）；
- 点删除 → 却仍然只删“第 N 周”这一周，第 N 周之后的周次原样留着（错误）。

根因：删除回调只带一个布尔值（`applyToAll`），界面把 `CourseEditScope.FROM_CURRENT_WEEK` 当成“只删本周”处理，
所以三档范围里只有两档能作用到删除上。

## 三档范围与操作对照（修复后）

| 保存范围 | 保存 | 删除 | 删除按钮文案 |
|---|---|---|---|
| 只改被编辑的这一周（默认） | 只改第 N 周这一次课 | 只从第 N 周移除这一次课 | 删除本周 |
| 应用到本周及以后周次 | 第 N 周起全部改写 | 第 N 周及之后全部移除，早于第 N 周的周次不动 | 删除本周起 |
| 应用到全部周 | 整门课程一起改写 | 整门课程全部周次移除 | 删除全部 |

“删除本周起”在确认弹窗里写明实际范围：
“将从第 N 周起移除「课程名」的后续周次，第 N 周之前的周次不受影响。删除后可在提示条中撤销。”

## 改动

- `data/model/Course.kt`：新增 `CourseSeriesOperations.deleteFromWeekOnward(courses, seriesKey, week)`，
  只摘除该系列第 N 周及以后的周次；记录被摘空时整条移除；`deleteWeek` 与它共用同一个私有实现，避免两处语义漂移。
- `ui/screen/CourseEditDialog.kt`：`onDelete` 由 `(Boolean) -> Unit` 改为 `(CourseEditScope) -> Unit`；
  删除按钮文案与确认文案随范围变化；删除按钮按最长文案分到更宽的一份宽度，并用 `TextOverflow.Ellipsis` 兜底。
- `MainActivity.kt`：删除动作按 scope 分派到 `deleteAll` / `deleteFromWeekOnward` / `deleteWeek`；
  撤销快照 `CourseSeriesUndo` 与提示条文案同步为三种（含“已从第 N 周起移除 X”）。
- `res/values/strings.xml`：新增 `edit_delete_from_week`、`edit_delete_from_week_message`、
  `main_snackbar_removed_from_week_onward`。

## 课程编辑入口核对

| 入口 | 是否受三档范围影响 | 结论 |
|---|---|---|
| 编辑器保存（字段／节次／周次） | 是 | v3.4.24 起已按 scope 分派，保持不变 |
| 编辑器删除 | 是 | 本轮修复，三档全部生效 |
| 新增课程 | 不适用 | 没有删除入口，保存固定为整学期周次 |
| 详情页“从本周移除课程” | 否（独立入口） | 只移除被点中的那一次课，弹窗文案已写明“只从第 N 周移除”，不提供范围开关 |

## 回归

- JVM：`CourseSeriesOperationsTest` 新增范围删除用例——只保留锚点之前的周次、跨系列隔离、拆周记录被摘空后整条移除、
  全部周次都在锚点之后时课程整体消失、只删本周的旧语义不回退、定向撤销可完整还原。
- 界面：`CourseEditorWeeksTest` 新增三档删除标签与回传范围用例，最长文案“删除本周起”在 320dp 窄屏下
  必须单行且完整落在删除按钮内（`getUnclippedBoundsInRoot` 断言），新增课程没有删除入口。
- 落盘：`CourseWeeksPersistenceTest.deletingFromThisWeekOnwardOnlyRemovesLaterWeeksOnDisk`——
  第 1-5 周的课在第 3 周按范围删除后，磁盘上只剩第 1-2 周，课程没有被整段删除。
- 视觉证据：`交付记录/v3.4.27-删除范围/delete-from-week.png`（编辑器三类按钮与“删除本周起”实际渲染）。

## 边界

数据格式仍为 schemaVersion 4，包名与升级签名不变；不改变导入、原子写入与既有调课语义。

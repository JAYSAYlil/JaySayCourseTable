# v3.4.17 代码与性能整理验证

日期：2026-09-07。版本：3.4.17 / versionCode 137。

## 等价优化

- 周视图与顶部统计复用按星期建立的课程索引。解析一周时，每天只检查对应星期的候选课程。
- 月视图每页只建立一次星期索引，并复用主屏已经生成的课程颜色映射。
- 周分页不再对常规课程执行第二遍搜索，也不再为星期未变化的课程创建副本；补课搜索语义保持不变。
- 课程的配色键、导入键与系列键随不可变实例一次计算，避免绘制和列表操作反复拼接字符串或计算 UUID。
- 搜索复用正则并直接匹配课程名、教师和教室，避免逐课程创建列表与合并字符串。
- 日期例外、校历状态和当前时间线改为单次遍历，移除中间 `filter`、`mapIndexedNotNull`、`Triple` 和重复计数。

## 验证标准

- JVM 单元测试覆盖搜索、日期例外、课程系列操作、当前时间线以及其余数据逻辑。
- Debug、Release 与 Lint 构建必须全部通过。
- Android UI 测试必须在 API 34 模拟器通过；签名 APK 必须完成覆盖安装和版本核验。
- 周视图 Macrobenchmark 使用 42 门虚构课程、3 次预热和 5 次测量。模拟器执行环境在重复运行间出现窗口调度波动，因此只将场景 0 失败作为连通性回归证据，不报告虚假的真机提升比例。
- 最终回归已通过：`testDebugUnitTest`、`connectedDebugAndroidTest`（61/61）、`lintRelease` 与 `assembleRelease`。签名包已在 API 34 模拟器以全新安装方式核验为 `3.4.17 (137)`。

## 兼容性

# v3.4.28 界面与动效改进

参考：[Emil Kowalski skills](https://github.com/emilkowalski/skills) 的 Apple Design、animate 与 improve-animations。应用仍为 Android Compose；借鉴层级、反馈与空间连续性，不复制 iOS 系统导航行为。

## 发现与处理

| 问题 | 处理 | 保留的交互契约 |
| --- | --- | --- |
| 各页面混用默认按钮、描边输入框、开关与选择块 | 共用 NativeControls：圆角矩形按钮、柔和填充输入框、固定大小滑块和居中选择块，移除涟漪 | 输入法、焦点、错误态、禁用态及切换语义 |
| 表面层级依赖色调叠加与大量描边 | 浅灰分组底色、白色内容面板；深色显式中性颜色；普通面板不描边 | 课程自定义颜色、深色课程渐变、自定义背景透明度 |
| 多个底部面板的按钮直接销毁面板 | hide 完成后执行动作；关闭期间忽略重复点击 | 确认一次、取消不变更数据、系统返回和下拉关闭 |
| 编辑器/确认框被移除时没有对称退出 | 居中弹窗使用窗口拥有的缩放淡入/淡出 | 不提前关闭校验失败或保存失败的表单 |
| 详情下拉每帧经过弹簧，只有头部移动 | 内容整体直接跟随，释放后才回弹；阈值按 dp 换算 | 原 Hero 返回配对、编辑/删除入口与滚动 |
| 学期安排仍使用默认日期弹窗 | 复用现有日历面板 | 选择日期与确认保存语义 |

覆盖课表周/日/月视图的公共操作、详情、编辑、新增、设置、多课表管理、学期安排、日程、历史、导入确认和备份相关弹层。没有新增功能或改写业务存储。

## 实现边界

- 表单输入改用 Foundation 的 BasicTextField；保留 Compose 原生输入、焦点及弹层手势基础实现，视觉由应用统一控制，不以移除 Material3 依赖库为目标。
- Compose 动画继续服从 Android 动画时长设置；窗口动画由系统窗口动画设置控制。没有新增独立的动画设置。
- 高频切周保留 Pager 的直接拖动，不追加出场等待或列表逐项入场。
- 截图测试仅使用虚构课程，保存在模拟器应用外部目录，不入库。
- API 34 模拟器的回归不能替代所有厂商小窗设备的上机验证。

## 验证

定稿前复核补充：① 面板确认动作改为 `CoroutineStart.UNDISPATCHED` + `NonCancellable`，收起期间宿主把面板移出组合不再丢失动作；
② 详情页下拉手势只以阈值为 key 并用 `rememberUpdatedState` 读取最新回调，拖动中父级重组不再重建处理器。两条回归用例在修复前均复现失败（分别报 expected 1 commits / 内容卡在拖到的位置）。
③ 下拉阈值回调到 v3.4.27 手感（88dp／300dp·s⁻¹）；④ 单选未选中补外环、点课表名补按压反馈；⑤ 日历与时间面板的中文字面量移入 strings.xml（星期数组、时/分后缀、转轮无障碍描述）。

新增控件开关/禁用语义、面板退出前不提交/重复点击只提交一次、大字体窄弹窗操作可达性回归，并扩展浅深色编辑器和详情、学期安排截图。详情手势覆盖短拖拽回位、长拖拽只关闭一次；系统截图捕获到居中弹窗退出中间帧，确认实际发生缩放淡出。最终结果见 DEVELOPMENT_STATUS.md。
